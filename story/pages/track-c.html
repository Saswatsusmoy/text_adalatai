C1c v2 -- careful extend (method OK, quality fail)

Script: vocab_extend_nllb_v2.py. Rules:

  1. Surface forms only (strip SPM underline).
  2. Add only if base NLLB fragments into >= 2 pieces.
  3. Reject protected-substring / probe regressions (e.g. keep न्यायालय intact).
  4. Mean-init new rows from base subword embeddings.
  5. Train LoRA + grad-mask only new emb rows (new_embed_start).

Checkpoint bug found: with modules_to_save=null, PEFT saved LoRA only (~12MB) and dropped trained emb rows. Fix: write new_embed_rows.pt and apply on load/eval. Retrain required before scoring.

Decision

Careful extend is documented methodology, not a quality win on an A1 budget. Production stays Track D A2. Optional later research: longer emb warm-up or C1c -> A2 resume.

Takeaway for the assignment

Optional vocab work was completed with controls (v1 vs v2, probes, emb save). The honest answer is that token packing improved under domain SPM, but integrating that vocab into NLLB did not beat stock priors under light adaptation -- so production refuses the fancy path.
