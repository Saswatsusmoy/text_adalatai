The ML assignment asks for a prototype legal EN->HI system with five workstreams and two deliverables (report + modular code). This page maps every requirement to concrete work in this repository so a reader (or interviewer) can verify completeness without hunting.

Objective (from the brief)

  1. Improve token efficiency for Indic languages (e.g. Hindi) under LLMs.
  2. Perform small-scale fine-tuning / adaptation for high-fidelity domain translation.

Scope is prototype-level (about 12-16 focused hours). This project intentionally went deeper on dual-track research, but the submittable path still has a single-GPU smoke recipe.

Task 1 -- Evaluate and optimize tokenization

Asked: compare at least two tokenizers; analyze token-per-word-like ratios, input length / inference cost; optional vocab merge/extend.

Done:

  • Cross-family survey: SentencePiece Unigram, multilingual BPE (NLLB / o200k), byte-level BPE (Llama-line).
  • Metrics: HI chars/token, HI/EN token ratio, total tokens on 1,458 pairs.
  • Domain SPM v1 (Prarabdha mono HI 16/32/41k) and v2 joint full Unigram (41/48/64k ablation).
  • Optional vocab extend on NLLB (C1c v1 bulk, C1c v2 careful) with embedding updates.

Where: src/tokenizer/, src/training/vocab_extend_nllb*.py, page Tokenizers, dumps in data/analysis/tokenizer_*.json.

Task 2 -- Prepare the dataset

Asked: light preprocessing; train/dev/test ~80/10/10; keep sentence alignment and legal formatting where possible.

Done:

  • Hindi OCR (Tesseract), EN line join, spaCy/danda segmentation, LaBSE mutual-best alignment.
  • Filters: min similarity 0.5, EN:HI char ratio 0.3-3.0, near-dedup.
  • Document-level split seed 42 -> 1,136 / 132 / 190 (not sentence-random).
  • Optional public legal parallel: MILPaC + Anuvaad Stage A (~993k filtered).

Where: src/preprocessing/, page Data pipeline.

Task 3 -- Model adaptation

Asked: lightweight translation model; light FT; LoRA/adapters; update embeddings if tokenization changes; single-GPU feasible.

Done:

  • Model: facebook/nllb-200-distilled-600M (enc-dec MT, not a chat LLM).
  • PEFT LoRA profile decoder_attn, ~0.5% trainable params.
  • Curriculum: smoke -> A1 (80k) -> A2 (150k resume); Stage B / B' ablations.
  • Vocab path: Marian C1 scaffold; C1c extend with emb resize / grad-mask / new_embed_rows.pt.
  • Configs: configs/training.yaml (local) and configs/training_h200*.yaml (optional remote).

Where: src/training/, pages Track D and Track C.

Task 4 -- Evaluation

Asked: BLEU, chrF (optional COMET); qualitative legal examples; before/after fidelity and token usage.

Done:

  • sacreBLEU BLEU + chrF++ on Policy I and Policy E (MILPaC + Anuvaad).
  • Before/after: zero-shot vs A1/A2/B/C1c full tables.
  • Token usage tables for domain SP vs general tokenizers.
  • Qualitative: revisional court, Article 142, writ petition, appellant role, archaic phrasing.
  • COMET optional -- not run; listed as next step.

Where: src/evaluation/, pages Scoreboard and Qualitative.

Task 5 -- Reflection

Asked: what worked / did not; how to improve; scale to more languages or harder legal text.

Done: written reflection, failures log, scale suggestions (COMET, replay, multi-Indic, full-doc translate).

Where: pages Reflection and Failures; also REPORT.md §6.
