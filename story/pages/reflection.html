Assignment task 5: what worked, what did not, how to improve, and how this scales beyond one language pair or one court corpus.

What worked

  • Document-level splits -- no judgment leakage into test.
  • OCR over PDF text layer for Hindi -- ligature damage is worse than OCR noise; enforced by a hard verify-ocr gate.
  • Dual-policy I + E -- Stage B would have shipped incorrectly without E.
  • LoRA on NLLB decoder attention -- cheap (~0.5% params), real dual-policy gains.
  • Curriculum A1 -> A2 -- small curated Stage A first, then scale resume.
  • Domain SentencePiece science -- clear packing evidence vs byte-level BPE; freeze made matrix-consistent.
  • Documenting failures (bulk C1c, pure Stage B) as first-class results.
  • Harness hardening -- enforced anti-forget caps + z-scored selection, NaN-safe DDP, MPS fp16 scaling, frozen-pool hash verification, run registry, bootstrap CIs + paired difference CIs, report fingerprints, COMET cache invalidation, legal-entity panel. These turned "trust me" numbers into reproducible, interval-carrying results.

What did not

  • Custom vocab + short LoRA budget did not beat NLLB priors (C1c v2 still below ZS).
  • Assignment-only Stage B overfits I and forgets external legal.
  • MBR at the tried config (N=8, top_p=0.9, chrF utility) lost to beam4; larger N / lower T / COMET utility not yet tried.
  • OCR HI references can be truncated -- metrics mix model and ref error (a ref-cleaned column now isolates the artifact).
  • Reference-free QE (CometKiwi / xCOMET) and a full legal-error panel are still gaps (the entity panel covers part of it).

Recommended combos

  • Best single lever: Tier 1 §1 (NLLB-1.3B) -- biggest gain, lowest risk, one config change.
  • Best two-lever combo (~1 day H200): Tier 1 §1 + Tier 1 §2 (1.3B + back-translation). Independent axes, additive gains, each classically defensible. Estimated +3-5 BLEU on I_test.
  • Modern-technique story: Tier 1 §1 + Tier 1 §3 (1.3B + CPO). Frontier flavour but harder to defend if drilled on CPO length bias / KL / reward hacking.
  • Assignment-fidelity story: Tier 1 §1 + Tier 3 (constrained decode) + qualitative rerun on same REPORT §5 examples.

None of the above were executed in this submission. Every entry names the actual paper / technique, expected delta, and H200 cost so a follow-up run is deterministic. Deltas are literature estimates on comparable MT benchmarks, not measured on this corpus.

Scaling to more languages / harder legal text

  1. Reuse the dual-policy contract: internal gold docs + external legal holdouts.
  2. Prefer NLLB / IndicNMT-class priors + LoRA over from-scratch small models when bitext is limited.
  3. Domain SPM for cost if you control the full stack; do not assume vocab surgery is free.
  4. For new Indic pairs: Stage A legal bitext (or government/court digests) -> curriculum subsample -> dual eval -> light Stage B with replay.
  5. For harder texts (statutes, multi-judge benches): add glossary constraints and document-level consistency passes.

Feasibility vs prototype scope

The assignment asks for Colab-class depth. Smoke training and full preprocessing run on a laptop. The dual-track scoreboard used optional H200 time. That is extra rigor, not a requirement -- the production story remains "LoRA on NLLB with dual-policy selection."
