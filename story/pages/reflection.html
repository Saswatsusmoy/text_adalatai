Assignment task 5: what worked, what did not, how to improve, and how this scales beyond one language pair or one court corpus.

What worked

  • Document-level splits -- no judgment leakage into test.
  • OCR over PDF text layer for Hindi -- ligature damage is worse than OCR noise.
  • Dual-policy I + E -- Stage B would have shipped incorrectly without E.
  • LoRA on NLLB decoder attention -- cheap (~0.5% params), real dual-policy gains.
  • Curriculum A1 -> A2 -- small curated Stage A first, then scale resume.
  • Domain SentencePiece science -- clear packing evidence vs byte-level BPE.
  • Documenting failures (bulk C1c, pure Stage B) as first-class results.

What did not

  • Custom vocab + short LoRA budget did not beat NLLB priors (C1c v2 still below ZS).
  • Assignment-only Stage B overfits I and forgets external legal.
  • Legal error panel / glossary QA not automated (still a gap; COMET-22 is now run and reinforces the BLEU/chrF++ ordering, see Scoreboard).
  • OCR HI references can be truncated -- metrics mix model and ref error.

Scaling to more languages / harder legal text

  1. Reuse the dual-policy contract: internal gold docs + external legal holdouts.
  2. Prefer NLLB / IndicNMT-class priors + LoRA over from-scratch small models when bitext is limited.
  3. Domain SPM for cost if you control the full stack; do not assume vocab surgery is free.
  4. For new Indic pairs: Stage A legal bitext (or government/court digests) -> curriculum subsample -> dual eval -> light Stage B with replay.
  5. For harder texts (statutes, multi-judge benches): add glossary constraints and document-level consistency passes.

Feasibility vs prototype scope

The assignment asks for Colab-class depth. Smoke training and full preprocessing run on a laptop. The dual-track scoreboard used optional H200 time. That is extra rigor, not a requirement -- the production story remains "LoRA on NLLB with dual-policy selection."
