Terms used throughout the walkthrough and report, grouped by phase. Every term maps to code in src/ or a decision in DESIGN_DECISIONS.md.

Data & preprocessing

TermMeaning
Policy IInternal assignment eval (test docs 1,4,21; dev docs 8,9,24).
Policy EExternal legal holdouts (MILPaC + Anuvaad) never in Stage A train; the anti-overfit guard.
danda (।)Hindi sentence terminator. A sentence's last unit usually carries it; OCR hard-wraps split it across lines, which the line-join step fixes.
Hindi line-joinjoin_hindi_lines.py: danda-aware joining of OCR hard-wrapped lines so a logical sentence survives as one unit. Idempotent (verified fixed point).
0.6 alignment floorMIN_SIMILARITY = 0.6: LaBSE mutual-best pairs below 0.6 are dropped, plus a 0.01 winner-vs-runner margin that kills tie duplicates.
verify-ocr gatemake verify-ocr: hard check that preprocessed/ is Tesseract OCR (Devanagari floors + text-layer markers), exits 1 on degradation. Enforced after the doc-6 regression.
LaBSESentence embedding model used for EN-HI mutual-best alignment.
mutual-bestKeep an EN-HI pair only when each side is the other's nearest LaBSE neighbor (not DP -- the similarity matrix is ~0.1% dense).
Stage APublic legal EN-HI bitext (~993k filtered): MILPaC (CC BY-NC-SA) + Anuvaad legal (CC BY), used for domain LoRA.
doc-level splitTrain/dev/test split at the document level (seed 42) so the same judgment never spans splits; IDs frozen in src/config.py.

Training

TermMeaning
Track DDefaults track: stock NLLB tokenizer + LoRA. Production path.
Track CCustom domain SPM + model adapt experiments (vocab-extend).
A1Stage A curriculum first: ~80k curated pairs, LoRA from base NLLB.
A2Stage A scale: 150k pairs, resume A1; production dual-policy pick.
Stage BAssignment-only specialize; failed external anti-forget without replay.
B'Stage B with assignment + Stage A replay mix (anti-forget method works, still not a dual-policy winner).
LoRALow-Rank Adaptation PEFT; ~0.5% params on decoder_attn profile.
decoder_attnLoRA on decoder self-attn and encoder-decoder cross-attn (the MT alignment hinge).
z-scored primaryStage B checkpoint selection: z_i = (s_i - mean_i)/std_i, primary = sum(w_i*z_i)/sum(w_i). Makes 0.7/0.3 weights mean what they say across differently-scaled suites.
anti-forget capsstage_b_max_drop_<suite>: reject a checkpoint whose suite drops more than the cap vs baseline. Enforced in selection.py (was YAML-only).
best_primaryCheckpoint with best dual-policy primary score on dev; saved to checkpoints/best_primary.
new_embed_rows.ptSaved new embedding rows for C1c v2 (not in the PEFT LoRA adapter); resume raises if missing when new_embed_start is set.
global batch parityglobal_batch_parity warns/raises when batch*world*accum != train.global_batch_size (local MPS 16 vs H200 32 is explicit).
pool hash verifyverify_pool_hashes checks the file_sha256 prefix of every frozen subsample against its manifest at launch.
run registrydata/runs/runs.json: maps run_id to config snapshot, data manifest, logs, best checkpoint -- no grep archaeology.
GradScaler('mps')MPS fp16 training with fp32 master weights + mps autocast + scaling; CUDA bf16 unchanged.

Evaluation

TermMeaning
chrF++Primary HI quality metric (char n-grams + word unigrams, word_order=2).
BLEUsacreBLEU lexical overlap; reported but weaker alone for HI.
bootstrap CIPer-suite 95% confidence interval from sacreBLEU's built-in bootstrap (mean, ci_low, ci_high), seeded for reproducibility.
paired diff CI--compare-tags A,B: paired-bootstrap 95% CI on the corpus metric delta between two systems, with a significant flag.
fingerprintConfig + hyp-file SHA256 recorded per report; resume refuses to mix rows decoded under a different config (--force-resume overrides).
TERTranslation Edit Rate (sacreBLEU), lower is better; makes verbosity visible.
len_ratiosys_len / ref_len per suite; exposes the ~1.377x verbosity that BLEU's missing brevity penalty hides.
ref_cleanedBLEU/chrF++ on references with OCR/list-marker artifacts stripped (refs only, labeled, additive).
entitiesLegal-entity recall/precision/F1 per suite (probes + case citations + dates, cross-script canonicalized).
COMET-22Reference-based neural metric (Unbabel/wmt22-comet-da); cache keyed on hyp-file SHA256 + model (schema v2).
MBRMinimum Bayes Risk decode: sample N, output argmax mean pairwise chrF utility; seeded (12345) for reproducibility.
