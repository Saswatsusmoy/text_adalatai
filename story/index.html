1 · Problem and constraints

Problem

EN→HI translation for Indian court judgments. Two pillars: (1) Indic token efficiency, (2) domain MT quality. Input: 30 parallel SC judgments (PDF + text). Output: reproducible preprocess → train/eval → production adapter.

Constraints enforced

  • Document-level train/dev/test freeze (seed 42). No re-split.
  • SPM train text: Stage A + assignment train only. Never assignment dev/test docs.
  • MT train never uses assignment test. Stage A train excludes Policy E holdouts.
  • Final claims: beam 4, max_new 256, max_in 256, batch 32, bf16 H200.
  • Dual metrics: Policy I (assignment) + Policy E (external holdout).
  • Remote H200: no kill root vLLM without owner OK.

Hindi extraction: 5 backends

All 30 HI PDFs use custom font encoding (ligatures as glyph components). Text-layer tools share the same broken stream. Doc 17 text layer transliterates (e.g. Ekkuuh;).

Doc6 quality: pdftotext प्रति वेद्य / सिसविवल vs Tesseract प्रतिवेद्य / सिविल. Ligature damage hits most conjuncts (~60–70% common HI words). Chose OCR despite ~220× slower (~3 min / 30 docs on M4).

Result: 5 corrupted docs restored (+42,536 Devanagari chars). Full judgment text in data/hindi/preprocessed/ (headers+parties+body), not paragraph-only clean.

Decision

Default: tesseract -l hin --psm 6. Fallback: --backend pdftotext.

3 · Tokenizers

Cross-model survey

Bench: assignment pairs; chars/token, HI/EN ratio, Dev vocab presence. Families: SentencePiece Unigram, multilingual BPE (o200k, NLLB), byte-level BPE (Llama-line).

Result: byte-level BPE weak (often 0 Dev tokens, UTF-8 byte fallback, ~1.1–2.7× HI cost). Multilingual BPE with Dev pieces OK. Domain Unigram SP strong on legal HI. Note: “BPE bad” is wrong; byte-level / Dev-blind BPE is the failure mode.

Train contract (Track D)

  • PEFT: LoRA r=16 α=32 dropout 0.05, profile decoder_attn (~0.5% params)
  • A1: 80k, 3000 steps, LR 1e-4; A2: 150k resume A1, LR 5e-5; B: 1136 resume A2, 800 steps, LR 3e-5
  • H200: global batch 32 (16×2), bf16, TF32, Flash SDPA, pad fixed mult 8, compile off under DDP
